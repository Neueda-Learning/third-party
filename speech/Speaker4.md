# Speaker 4 – Challenges & Conclusion

Thank you. I'm Merry.

During development, we faced two main challenges.

First, every team member proposed a different design. We used AI to compare the four proposals, discussed the results and agreed on one unified architecture before coding.

Second, Git merge conflicts were unavoidable because everyone worked on separate branches. We reviewed the conflicting code together and reached a common solution before merging.

If we had more time, we would add multi-currency support, webhook notifications, batch payments and payment reversal.

This project helped us practice backend development, REST API design, database modelling, Git collaboration and teamwork.

Thank you very much for listening. We'd be happy to answer any questions.
